## Automedon - محفظة أعمال بتقنية التوأم الرقمي المدعوم بالذكاء الاصطناعي

**سبب بناء المشروع**: السيرة الذاتية وثيقة ثابتة لا تجيب إلا عن الأسئلة التي توقّعها كاتبها، فينتهي الأمر بمسؤولي التوظيف إلى البحث عن كلمات مفتاحية بدل طرح ما يهمهم فعلاً. يقلب Automedon هذه المعادلة: محفظة أعمال يمكن محادثتها، يدعمها مساعد يعتمد حصرياً على سيرتي الذاتية وسجل مشاريعي وخبرتي المهنية — بلا مؤهلات مُختلقة وبلا إجابات خارج المصدر.

**التنفيذ التقني**

**البنية المعمارية**: Next.js 15 مع App Router و React 19 و TypeScript في الوضع الصارم. يوجد المحتوى بالكامل خارج الكود في `portfolio-data/{locale}/portfolio.json`، ويُقدَّم عبر مسارات API مع التحقق من صحته بدل استيراده وقت البناء. تحديث المحفظة يعني تعديل ملف JSON وإعادة التشغيل — لا إعادة نشر للتطبيق.

**الاكتشاف الديناميكي للغات**: بدلاً من تثبيت قائمة لغات في الكود، يمسح الخادم مجلد `portfolio-data/` عند الإقلاع، ويعتبر كل مجلد فرعي يحتوي على `portfolio.json` لغةً متاحة، ويقرأ ملف `locale.json` الاختياري للحصول على الاسم الأصلي والعلم وخاصية الاتجاه من اليمين إلى اليسار. تُخزَّن النتائج مؤقتاً على مستوى الوحدة، فلا يُمسح نظام الملفات إلا مرة واحدة. إضافة لغة خامسة تعني إنشاء مجلد وإعادة تشغيل — دون أي تعديل على الكود.

**التعريب والتدويل**: أربع لغات متاحة حالياً (الإنجليزية والفرنسية والألمانية والعربية)، مع دعم كامل لتخطيط الاتجاه من اليمين إلى اليسار في العربية. يُحدَّد اختيار اللغة عبر معامل في الرابط مع الاعتماد على `localStorage` كخيار احتياطي، ويتبدّل المحتوى دون إعادة تحميل الصفحة. كل نص ظاهر للمستخدم — أوصاف المشاريع وفئات المهارات ونصوص التواصل — مترجم، ولكل لغة ملفات Markdown مفصّلة خاصة بها لعرض تفاصيل المشاريع.

**إدارة الحالة والعرض**: تُقسَّم الحالة العامة حسب المسؤولية على ثلاثة سياقات في React (`LanguageContext` و`PortfolioDataContext` و`ThemeProvider`) بدل مخزن واحد. بُنيت الواجهة من مكوّنات Radix الأساسية مع Tailwind CSS 4، ضمن نظام تصميم يعتمد تأثير الزجاج، مع Motion لحركات تُفعَّل عند التمرير وتحترم إعداد `prefers-reduced-motion`.

**منظومة أيقونات التقنيات**: سلسلة استبدال متدرّجة (base64 ← رابط خارجي ← أيقونة Lucide احتياطية) تُغذّي شارات التقنيات، مع انتقال من التدرّج الرمادي إلى الألوان عند تمرير المؤشر على البطاقة. ولا تزال المصفوفات النصية القديمة مدعومة إلى جانب الصيغة الكائنية الجديدة، ما يتيح ترحيل ملفات البيانات تدريجياً.

**النشر**: نهج يعتمد Docker أولاً، مع صورة مبنية مسبقاً تتجاوز مشكلة الملفات الثنائية الأصلية لـ `lightningcss` في Tailwind CSS 4. تعمل الحاوية بمستخدم غير جذري، مع فحوص سلامة وحدود موارد محددة.

**التقنيات المستخدمة**

| الطبقة | الاختيار |
|---|---|
| إطار العمل | Next.js 15 (App Router)، React 19 |
| اللغة | TypeScript 5، الوضع الصارم |
| التنسيق | Tailwind CSS 4، Radix UI، Motion |
| المحتوى | ملفات JSON و Markdown تُقدَّم عبر مسارات API |
| النشر | Docker، Docker Compose |

**الحالة**: المحفظة ونظام تعدد اللغات وعرض المشاريع في الخدمة فعلياً. أما طبقة الذكاء الاصطناعي الحوارية فهي العمل الجاري حالياً — تُعرض الواجهة خلف نافذة «قيد التطوير» ريثما يكتمل بناء الواجهة الخلفية للاسترجاع والاستناد إلى المصادر.
